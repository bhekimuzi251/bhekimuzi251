# MediGo App (MVP)

A lightweight single-page web app for the MediGo concept.

## Features
- Hero landing page and service overview
- Consultation booking form (front-end validation)
- Subscription plans section (Basic + Premium)
- Dark/light theme toggle with localStorage persistence

## Run locally
Open `index.html` directly in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
